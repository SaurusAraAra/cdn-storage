Cara Pakai

Semudah satu baris.

Tidak perlu daftar akun, tidak perlu instalasi. Langsung jalan.

01
Pilih API yang kamu butuhkan
Buka dokumentasi — cari berdasarkan kategori atau keyword. Ada ratusan pilihan.
02
Kirim request ke URL endpoint
Akses URL dengan parameter yang dibutuhkan. Contoh: GET /api/search/lirik?q=nama+lagu
03
Dapat response JSON siap pakai
Semua API return JSON terstruktur — langsung bisa dipakai di bot, website, atau script apapun.
