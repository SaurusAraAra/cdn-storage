Cara paling simpel (tanpa app tambahan):
1. Buka gist.github.com (gratis, pakai akun GitHub)
2. Buat file JSON berisi config yang mau di-update
3. Klik "Raw" → copy URL-nya
4. Paste di sini. Semua device auto-dapat update saat buka website.

Contoh isi JSON: {"aiName":"Veyzen AI","apis":[...]}
